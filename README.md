# رزومه آنلاین تعاملی

رزومه/پورتفولیوی شخصی با Vite، Tailwind CSS و Vanilla JS.

## پیش‌نیاز

- Node.js 18+

## اجرا

```bash
npm install
npm run dev
```

آدرس: http://localhost:5173/

## بیلد پروداکشن

```bash
npm run build
npm run preview
```

خروجی در پوشه `dist/` قرار می‌گیرد.

## شخصی‌سازی

اطلاعات و متن‌ها: `src/data/content.js`  
فونت فارسی: `public/fonts/`  
استایل‌ها: `src/style.css`
